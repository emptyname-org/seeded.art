About seeded.art

Seeded.art is an archive of NFTs rescued from fxhash after its shutdown. It preserves the platform’s projects, NFTs, artist and collector profiles, and articles. Each NFT runs the artist’s original code in a browser, using the seed recorded when it was minted. Please use the forum for all communication.

Available now

  • Browsing and searching projects, NFTs, seeds, artists, collectors, sales history, and articles from fxhash.
  • Running NFTs from their original code. Seeded.art stores a verified copy of each project’s code so the works can continue to run even if fxhash or IPFS gateways become unavailable.
  • Managing your profile. Signing in with a Tezos wallet to add or edit your name, bio, and links.
  • Managing existing offers. Accepting or cancelling offers made on fxhash before it shut down.

What’s next

The plan is for Seeded.art to grow into a full marketplace for generative NFTs, built around seeds. It will probably use a blockchain other than Tezos, but that hasn’t been decided.

A migration path for fxhash projects and NFTs is also planned. Only an NFT’s current owner would be able to initiate its migration to Seeded.art.

These plans are still evolving, and the details will change during development.
